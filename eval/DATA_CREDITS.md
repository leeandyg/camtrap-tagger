# Evaluation data credits

The evaluation in the main README used images from these datasets, hosted on
[LILA BC](https://lila.science). No images are included in this repository; `prepare_lila.py`
downloads samples from LILA.

## Oregon Critters

Released under the [Community Data License Agreement (permissive variant)](https://cdla.io/permissive-1-0/).
[Dataset page](https://lila.science/datasets/oregon-critters/).

- Appel CL, Lesmeister DB, Kay J, Hallerud M, Tosa MI, Levi T. Oregon Critters: A computer vision
  model for multispecies wildlife detection from two camera trap modalities. In review.

evaluation sample drew from all ten:

## ENA24-detection

[Dataset page](https://lila.science/datasets/ena24detection).

- Yousif H, Kays R, He Z. Dynamic Programming Selection of Object Proposals for Sequence-Level
  Animal Species Classification in the Wild. IEEE Transactions on Circuits and Systems for Video
  Technology, 2019.
